# 🎢 Exploratory Data Analysis (EDA) on Amusement Park

This project performs end-to-end Exploratory Data Analysis 
on a real-world roller coaster dataset to uncover patterns 
in coaster speed, height, G-force, and introduction trends 
across years and manufacturers.

## 🛠️ Tools & Libraries
- Python, Pandas, Matplotlib, Seaborn

## 📂 Dataset
- Source: coaster_db.csv (raw, messy real-world data)
- Records: ~1000+ roller coasters globally
- Features: Speed, Height, G-force, Year Introduced, 
  Location, Manufacturer, Type

## 🔍 What I Did
- Cleaned raw data: removed duplicates, handled nulls, 
  standardized column names
- Selected 13 relevant features for analysis
- Built 6+ visualizations to extract meaningful insights

## 📊 Key Insights
- Strong positive correlation found between coaster 
  speed and height
- Peak coaster construction periods identified 
  between 1999–2002
- Outliers in speed detected using the IQR method
